# Support & Community Help

Thank you for using **RollerSkater**! We want you to have a smooth experience playing and organizing your offline music library.

This document outlines the best ways to get help, ask questions, report problems, and participate in the RollerSkater community.

---

## 1. Where to Look First

Before opening a new issue or discussion, check these resources:

- **[README.md](README.md)**: Project overview, verified feature set, and quick-start instructions.
- **[Documentation Index](docs/README.md)**: Comprehensive guides covering installation, architecture, audio engine, database, and widgets.
- **[Troubleshooting Guide](docs/troubleshooting.md)**: Solutions for common playback, metadata indexing, permission, and audio effect issues.
- **[Frequently Asked Questions (FAQ)](docs/faq.md)**: Answers to commonly asked questions about offline features, formats, and hardware support.
- **[GitHub Discussions](https://github.com/dhyandevp/RollerSkater/discussions)**: Community Q&A and knowledge base.

## 2. Choosing the Right Channel

| I want to... | Best Channel | Notes |
|---|---|---|
| **Ask a general question or get setup help** | [GitHub Discussions — Q&A](https://github.com/dhyandevp/RollerSkater/discussions/categories/q-a) | Discuss device-specific quirks, workflows, or tag setups. |
| **Suggest a feature or improvement** | [GitHub Discussions — Ideas](https://github.com/dhyandevp/RollerSkater/discussions/categories/ideas) or [Feature Request Issue](https://github.com/dhyandevp/RollerSkater/issues/new?template=feature_request.yml) | Remember that RollerSkater is strictly an offline-first player. |

| **Report a security vulnerability** | [GitHub Security Advisory](https://github.com/dhyandevp/RollerSkater/security/advisories/new) | See [SECURITY.md](SECURITY.md) for private reporting procedures. |

## 3. Reporting Effective Bug Reports

When opening an issue, providing accurate context helps us resolve it quickly:

1. **Check for existing issues**: Search open and closed issues first to avoid duplicates.
2. **Device and OS Details**: Include your exact phone model (e.g. Pixel 8, Galaxy S23) and Android OS version (e.g. Android 14 API 34).
3. **App Version**: Specify the installed RollerSkater version (e.g. `v1.0.0` or git commit SHA).
4. **Steps to Reproduce**: Give numbered, repeatable steps from a fresh app launch.
5. **Expected vs. Actual Behavior**: Describe what you expected to happen versus what occurred.
6. **Logcat / Crash Logs (Sanitized)**: If reporting a crash, include relevant logcat lines. **Never include private audio file paths, personal tokens, or sensitive information.**
